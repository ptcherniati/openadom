\subsubsection{Etiquettes (OA\_tags)}\label{etiquettes-oa_tags}

\textbf{OA\_tags}: Création d'un regroupements sous une étiquette
permettant de filtré l'affichages des listes des
\hyperref[data]{\textbf{OA\_data}}. Mais aussi les
\hyperref[basicComponents]{\textbf{OA\_basicComponents}}, les
\hyperref[computedComponents]{\textbf{OA\_computedComponents}}, les
\hyperref[dynamicComponents]{\textbf{OA\_dynamicComponents}} d'un
\hyperref[data]{\textbf{OA\_data}}.

\AttributeTok{    }\FunctionTok{fr}\KeywordTok{:}\AttributeTok{ Profondeur}
\AttributeTok{    }\FunctionTok{en}\KeywordTok{:}\AttributeTok{ Profondeur}

Les étiquettes \texttt{\_\_DATA\_\_}, \texttt{\_\_REFERENCE\_\_},
\texttt{\_\_ORDER\_({[}0-9{]}*)\_\_} et \texttt{\_\_HIDDEN\_\_} sont des
étiquettes qui n'ont pas besoin d'êtres mise dans la liste de création.

\begin{itemize}
\tightlist
\item
  \texttt{\_\_DATA\_\_}: nous l'utiliserons pour les données qui ne sont
  pas des références (\texttt{\_\_REFERENCE\_\_} est le tag par défault
  pour une data)
\item
  \texttt{\_\_ORDER\_({[}0-9{]}*)\_\_}: nous l'utiliserons pour ordonner
  l'affichage des colonnes dans un ordre voulu (autre qu'alphabétique
  qui est l'ordre par default)
\item
  \texttt{\_\_HIDDEN\_\_} : nous l'utiliserons pour les données que l'on
  veux enregistrer en base mais que l'on ne veux pas rendre accessible à
  l'utilisateur.
\end{itemize}

Pour lier une ou plusieurs étiquettes avec une \emph{référence} ou une
\emph{colonne} il suffit d'ajouter une section \emph{OA\_tags} sous le
nom de la \emph{référence}, \emph{type de de donnée},
\emph{variable}/\emph{component} ou \emph{colonne} à lier.
