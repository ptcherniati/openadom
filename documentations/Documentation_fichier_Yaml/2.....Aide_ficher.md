
# <a id="aidefichier" />Rédaction du fichier de configuration

## <a id="creation" />La création :

Vous trouverez ci-dessous des exemples décrivant les parties attendues dans le fichier de configuration pour qu'il
soit valide. 

**Attention le format Yaml est sensible,** il faut donc respecter l'indentation.

Il y a 8 parties (<span style="color: orange">sans indentation</span>) attendues dans le fichier :

* version,
* [application](#application),
* [references](#references),
* [compositeReferences](#compositeReferences),
* [dataTypes](#datatypes),
* [tags](#tags),
* [additionalFiles](#additionalFiles)
* [rightsRequest](#rightsRequest)

<span style="color:orange">l'indentation du fichier yaml est très importante.</span>
